Typace

«Typography, beautifully organized.»

A quiet, offline-first font library for collecting and browsing local fonts.

Built with a single HTML file, a simple "fonts.json" index, and a "/fonts" directory.

<br>Philosophy

Less interface.
More typography.

No frameworks.
No build tools.
No unnecessary complexity.

<br>Structure

Typace/
├── index.html
├── fonts.json
└── fonts/

<br>Your Library

Typace doesn't ship with fonts.

Simply place your own font files in the "/fonts" directory and reference them in "fonts.json".

<br>«Typography deserves a quiet place.»
