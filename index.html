About Typace

Typace
A quiet font library

Typace is a lightweight place for discovering, previewing, and using typefaces.

CDN

Fonts are served through jsDelivr from the Typace GitHub repository.

https://cdn.jsdelivr.net/gh/aceyash-dev/Typace@main/fonts/<filename>
Usage

Add the generated @font-face declaration to your stylesheet, then use the font normally.

@font-face { font-family: 'Your Font'; src: url('CDN_URL') format('woff2'); font-display: swap; }
